# Global-superstore-Mysql-analysis
End-to-end SQL analysis of the Global Superstore dataset using MySQL. Covers data quality checks, business performance, customer segmentation, product profitability, and sales trends using CTEs, window functions, and advanced SQL techniques.

## Dataset Information

| Attribute | Description |
|---|---|
| Dataset | Global Superstore |
| Source platform | Kaggle |
| Number of transaction rows | 51,289 |
| Date range | 2011–2014 |
| Business domain | Retail sales |
| Database | MySQL 8.0 |

The dataset contains retail transaction information, including orders, customers, products, sales, profit, quantity, discounts, shipping, and geographical details.

**Source note:** The dataset was obtained from Kaggle. The exact original listing and uploader could not be identified.
